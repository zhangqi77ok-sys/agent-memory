# 第二十二轮设计：遗忘曲线（Ebbinghaus）——实施中

## 发现：经验衰减重复计费（本轮修掉）

`consolidate_insights` 的衰减按“自 last_used_at 起的全部块数”乘到当前
置信度，却没有结清锚点：每小时巡检跑一次，宽限期后实际是按小时复利，
不出两天就压到下限 0.1。单次调用的测试看不出（块数口径本身是对的），
多轮复利从未被测过。第二十轮给边衰减补 `decayed_until` 锚点时，经验侧
漏了——本轮补上（迁移 0022 给 memory_insight 加 decayed_until）。

## 锚点算法（总额与旧单次口径一致，只修重复计费）

- 基线 base = max(last_used_at 或 valid_from, decayed_until)。
- 锚点为空、或锚点 ≤ last_used_at（被用上刷新了时钟，宽限重算）：
  用宽限公式 blocks = (idle-1)//30，要求 idle > 30。
- 锚点新于 last_used_at（续扣）：blocks = idle//30，要求 idle ≥ 30，
  宽限不再重算——每满 30 天 exactly 一块。
- 扣完把 decayed_until 记到 now；退役判定仍用自 last_used_at 起的真闲置
  （不受锚点影响），180 天线不动。
- 对账：day 0 用过、day 40 首扣 1 块、day 70 续扣 1 块、day 100 续扣 1 块，
  合计 3 块 = 旧单次口径 day 100 的 (100-1)//30 = 3 块。测试断言此对账。

## 艾宾浩斯化：复述增强衰减率（经验侧）

- 复述计数 rehearsals = applied_count + feedback_pos（任务回流证实应用 +
  人工好评；曝光 use_count 不算，auto_pos 已含在 applied_count 里不重复计）。
- 月衰减因子 = 1 - 0.05 / (1 + rehearsals)：0 次复述 = 0.95（现状），
  复述越多因子越近 1（强记忆忘得慢），渐近不断崖。
- 因子只影响新增块数的乘子，不动宽限与下限；反馈/回流按计数重算置信度
  时仍覆盖衰减（第十一轮语义，保留）。

## 边衰减对齐（decay_idle_edges 扩展）

- 基线从“最近一次交付（无论是否应用）”改为“最近一次被证实应用的交付”
  （applied 的 BriefDeliveryEdge）：曝光不再重置边的遗忘时钟——与第十六轮
  “曝光≠用上”的口径一致。锚点 decayed_until 语义不变。
- 边侧因子保持 0.95 不动：边已有 strength_on_applied 做复述增强（第二十轮），
  本轮只对齐基线，不叠第二套复述参数（参数越少，行为越可测）。

## 度量：闲置记忆的前后召回变化

- 同一条闲置经验 consolidate 前后的简报分数：闲置组下降、复述组不变
  （测试断言分数方向，不编造生产数据）。
- 锚点对账测试（上）+ 复述因子测试 + 边基线测试（近期交付未应用仍衰减、
  近期应用则跳过）构成第 22 轮的度量口径，进 docs/eval.md。
- 面板本轮不动：遗忘度量是评测口径，先落测试与文档（面板身份/分页/
  溯源是下一轮的事，不混进本轮）。
